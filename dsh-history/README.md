# dsh-plugin-prompt-history

DSH Web 对话大纲/目录插件。在对话记录右侧常驻悬浮一个符合 DSH 官方质感的文档大纲窗口，逐行列出本会话收到的全部提示词并标明时间，点击即可平滑跳转到对应消息并高亮；面板顶部带有「加载全部」按钮，一键把更早的旧上下文全部载入。

## 设计特性与排版规范

### 1. 深度统一 DSH 网页设计语言
- **色彩与主题完全自适应**：严格使用 DSH 官方 Design Tokens（`--dsw-alias-bg-base`、`--dsw-alias-label-primary`、`--dsw-alias-border-l2`、`--dsw-alias-interactive-bg-hover` 等），在**浅色模式**和**深色模式**下都具备极高对比度，彻底杜绝白底白字或灰底暗字。
- **零 Emoji，纯净线框矢量图标**：完全摒弃 Emoji，内置 1:1 匹配 DSH 官方几何规格的超轻量线条 SVG 图标（大纲列表、下载箭头、微旋转 Spinner、完成对勾、搜索放大镜、关闭叉号）。

### 2. Word 风格常驻右侧目录
- **右侧悬浮窗口**：常驻悬浮在屏幕右侧（`right: 16px; top: 64px; bottom: 100px`），卡片圆角（`12px`），克制的外阴影，避开顶部导航栏与底部输入框。
- **可折叠收起**：右上角提供极简关闭按钮，收起后自动折叠为贴在屏幕右边缘的细长标签（带有向左指示箭头 +「目录」文字 + 数量徽标），点击随时滑出展开；折叠状态自动持久化到 `localStorage`。

### 3. 清晰结构化条目与跳转
- **条目层级**：
  - 上层元信息：`#1` 序号、居中小圆点、`HH:mm:ss` 时间戳（当天展示 `HH:mm:ss`，跨天展示 `MM-DD HH:mm`）、插话徽标。
  - 下层提示词主体：单行省略截断，清晰锐利。
- **一键平滑跳转与脉冲高亮**：点击目录中任意一行，主对话流平滑滚动到对应消息并居中，同时该行触发柔和的脉冲外发光动画（约 1.4 秒）。

### 4. 稳健的「加载全部」旧上下文引擎
- 当会话较长、存在未加载的历史时（`hasMore: true`），顶部提供高对比度「加载全部旧上下文」按钮。
- 点击后后台串行分页拉取（等待上一页真正落定后再发起下一页，避免并发拒绝），实时提示「正在加载第 X 页…」。
- 全部拉取完成后自动更新为「已加载全部上下文」并禁用。

### 5. 实时搜索过滤
- 输入超过 4 条时，顶部自动展开搜索框，支持秒级筛选历史输入。

## 生效方式

插件代码位于 `~/.dsh/plugins/dsh-plugin-prompt-history/lib/client.js`。
**重启一次 DSH Web（`dsh web`）并刷新网页**即可生效。
